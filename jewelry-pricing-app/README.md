\# 金工工作室報價系統 (Jewelry Pricing App)



專為珠寶金工與維修設計的自動化報價系統。支援即時金價換算、各項工藝費用試算，並提供多筆報價紀錄暫存與 Excel 匯出功能。



\## ✨ 系統特色

\* \*\*動態牌價換算\*\*：內建標準耗損係數自動計算（18K/14K 金預設係數 1.3，鉑金預設 1.25）。

\* \*\*執模雙色邏輯\*\*：自動判別雙材質組合並計算加成費用。

\* \*\*重量區間計價\*\*：執模台工與鑲嵌服務採用重量區間自動判定收費標準。

\* \*\*多筆紀錄匯出\*\*：可連續進行多筆報價，並一鍵匯出為標準 Excel (.xlsx) 檔案。



\## 🚀 部署方式

本專案支援一鍵部署至 Streamlit Community Cloud。請確保 `requirements.txt` 存在以正確載入 Excel 匯出所需之 `openpyxl` 套件。
