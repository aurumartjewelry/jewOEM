# 戒圍改大補金估算器

一個可直接部署到 GitHub Pages 的純前端計算器，專門估算台灣國際圍戒指「改大」時的 K 金補料金料重量。

## 計算邏輯

### 1. 增加內圍長度

使用台灣常用國際圍尺寸表：

- #12 = 53.4 mm
- #14 = 56.5 mm
- #12 → #14 = 3.1 mm

### 2. 理論成品增加重量

```text
戒腳體積增加量
= 戒腳寬度 × 戒腳厚度 × 增加內圍長度

理論重量
= 體積 × 材料密度
```

### 3. 建議投入補料金料

```text
建議投入重量
= 理論重量 × 加工係數
```

預設加工係數為 `1.15`。

例如：

```text
750K
戒腳 2.0 × 1.7 mm
#12 → #14

理論重量 ≈ 0.164 g
建議投入 ≈ 0.189 g
```

這與實務上約投入 `0.19 g` 的案例相當接近。

## 注意事項

1. 本工具估算的是「加工前投入的補料金料」，不是完成改圍後戒指的實際增加重量。
2. K 金密度不是只由成色決定，會因銀、銅、鈀等合金比例而變化；`app.js` 中的密度為估算值。
3. 戒腳若不是矩形截面，或有明顯弧度、造型、鑲口、局部厚薄變化，請調整加工係數。
4. 實務上建議蒐集歷史改圍案件，逐步建立你自己的「材質 × 戒腳尺寸 × 加工係數」資料。

## GitHub Pages 部署

1. 在 GitHub 建立新 repository。
2. 將 `index.html`、`style.css`、`app.js`、`README.md` 上傳到 repository 根目錄。
3. Repository → Settings → Pages。
4. Source 選擇 `Deploy from a branch`。
5. Branch 選 `main` / root。
6. 儲存後即可取得 GitHub Pages 網址。
