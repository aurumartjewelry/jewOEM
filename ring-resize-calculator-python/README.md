# 戒圍改大補金估算器

Python Tkinter GUI，估算台灣國際圍戒指改大時的補料金料與金料成本。

輸入：
- 成色：750、585、Pt950
- 原戒圍、改至戒圍
- 戒腳寬度、厚度（mm）
- 加工係數
- 金價（每錢）

輸出：
- 增加圍數
- 增加內圍長度
- 理論重量（g、錢）
- 建議投入補料金料（g、錢）
- 金料估算成本

公式：
理論重量 = 寬 × 厚 × 增加內圍長度 × 密度
建議投入重量 = 理論重量 × 加工係數
錢 = g / 3.75
金料成本 = 建議投入重量（錢）× 金價 × 成色比例

執行：
python ring_resize_calculator.py

程式只使用 Python 內建 tkinter，不需第三方套件。
